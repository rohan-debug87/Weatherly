# 🌦️ Weather App

A simple and responsive weather application built using **HTML, CSS, and JavaScript** that provides real-time weather information for any city in the world.

The app fetches live weather data from a weather API and displays important details such as temperature, humidity, and weather conditions in a clean and user-friendly interface.

---

## 🚀 Live Demo
🔗 https://rohan-debug87.github.io/Weatherly/

---

## 📌 Features

- 🌍 Search weather by city name
- 🌡️ Real-time temperature display
- 💧 Humidity information
- ☁️ Weather condition icons
- ⚡ Fast and lightweight
- 📱 Responsive design

---

## 🛠️ Tech Stack

- **HTML5** – Structure of the application  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – Logic and API handling  
- **Weather API** – Fetching live weather data  

---

## 📂 Project Structure

```
weather-app/
│
├── index.html      # Main HTML file
├── style.css       # Styling file
├── script.js       # JavaScript logic
└── images/         # Icons and assets
```

---

## ⚙️ How It Works

1. User enters a **city name**
2. The app sends a request to the **weather API**
3. API returns weather data in **JSON format**
4. JavaScript processes the data and updates the UI dynamically

---

## 📥 Installation

If you want to run this project locally:

```bash
git clone https://github.com/rohan-debug87/weatherly.git
cd weatherly
```

Then open `index.html` in your browser.

---

## 🔑 API Setup

If the project requires an API key:

1. Get a free API key from a weather service.
2. Add your API key inside `script.js`.

Example:

```javascript
const apiKey = "YOUR_API_KEY";
```
